# wing

wing is an iMessage travel agent that finds real flights around your schedule, watches prices, and helps organize trips. Flight reservations and airport rides are simulated.

## Tech stack

- TypeScript and Node.js
- Photon / Spectrum for iMessage integration
- Anthropic Claude API and Vercel AI SDK for conversation and tool use
- SerpApi for Google Flights searches
- Google Calendar API for schedule sync and calendar events
- Supabase / PostgreSQL for persistent data
- Supermemory for long-term memory
- Zod and Temporal for validation and date/time handling
- Railway and Docker for hosting
